Engine check and details

Single-threaded ffmpeg.wasm. No SharedArrayBuffer or cross-origin isolation required. The check makes a tiny synthetic video and runs a captioned vertical export locally.



V2 notes: Center crop, 720 × 1280, H.264 MP4 with AAC audio when present. Captions use the selected font in the lower third; optional larger titles sit at the top. White text has a navy outline. Cards use Gelasio headings on navy. This single-threaded core does not include drawtext: browser-loaded TTF fonts rasterize to transparent PNGs and ffmpeg burns those into the video. TTFs are also loaded into the engine filesystem. Segments use 720 × 1280, 30 fps, H.264 and stereo 48 kHz AAC; silent sources receive silence for reliable joins. Font previews in native option menus vary by browser; the large sample shows the selected face. No automatic transcription, tracking, accounts, API keys or subscriptions. Use current desktop Chrome or Edge for best results; Safari, Firefox and mobile may have memory or codec limits. MOV codecs vary; an unsupported source will show an error. Files over 500 MB are blocked; even smaller files can exceed browser memory. Downloads remain in this tab until refresh; save them before leaving. Nothing is saved between visits. Long captions shrink to fit; preview the output before posting. A ZIP temporarily uses extra memory.
